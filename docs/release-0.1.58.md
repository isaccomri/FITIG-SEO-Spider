# 0.1.58 — saved-crawl redirect and canonical report workbench

Adds Reports → Redirect and canonical reports with six independent report variants: All Redirects, Redirect Chains, Redirect & Canonical Chains, Redirects to Error, Canonical Chains and Non-Indexable Canonicals. Each report is a table with source/final status, hop count, outcome and complete JSON path/relationship evidence. Search applies to all columns; paging shows 200 rows and CSV exports all matching rows, not just the visible page. UTF-8 BOM CSV uses the existing typed table exporter.

Reports read saved observations only and require a stopped crawl. Missing targets have blank final status and a distinct unknown outcome; they are not treated as HTTP errors. Redirect-only paths stop before following canonicals; mixed paths start with an observed redirect then follow both relationship types. Canonical-only paths stop at an observed redirect. Self-canonicals terminate normally. Loops and a 1,000-hop limit are explicit. Output is capped at 50,000 included rows with a visible partial-output flag.

Chains are paths with more than one observed relationship, plus loops/safety-limit outcomes. Non-indexable canonical reports identify observed terminal HTTP errors, no response, noindex, redirects or loops; they do not certify indexing, intermediate-node restrictions, canonical equivalence or the complete competitor report taxonomy. Redirect-to-error requires an observed terminal HTTP status >=400, excluding unknown targets and no-response status 0.
