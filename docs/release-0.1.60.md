# 0.1.60 — crawl summary reports

Reports → Crawl reports includes Crawl Overview, Issues Overview, HTTP Header Summary and SERP Summary. This brings the workbench to 19 report variants. Each summary supports search and filtered CSV export from a saved crawl.

Crawl Overview groups recorded URLs by scope, status and media type. Issues Overview counts each recorded issue once per URL. HTTP Header Summary counts header names without exporting their values. SERP Summary shows saved titles and meta descriptions for successful internal HTML pages, with character counts. Search engines may display different text.

The CSV exporter prefixes formula-like text with an apostrophe so it opens as text in spreadsheet applications.

These reports cover saved crawl data. Full competitor report coverage and exact output comparison remain open.
