# 0.1.62 — JSON-LD reports

The Crawl reports workbench has 24 variants. JSON-LD Summary shows totals from the saved-crawl validator. JSON-LD Validation Findings lists recorded findings with source URL, block, pointer, severity and code. JSON-LD Parse Errors filters those findings to malformed JSON and unsupported top-level document shapes.

All three reports use saved data and the validator's default options. The workbench identifies partial output when the findings limit is reached. The summary retains the validator's aggregate counts.
