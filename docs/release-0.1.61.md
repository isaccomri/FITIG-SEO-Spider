# 0.1.61 — insecure references and orphan candidates

Reports → Crawl reports includes 21 variants. Insecure Content lists recorded HTTP links and resources referenced by HTTPS pages. Orphan Page Candidates reuses the saved link graph and inventory evidence from sitemaps, GA4 and Search Console. It shows the candidate URL, observed status, discovery sources and link evidence.

A candidate has no observed path from the crawl seed. Partial crawls and unobserved links limit that conclusion. The insecure-content report describes references found in crawl data. Browser blocking and automatic upgrades require runtime evidence.

The remaining acceptance checklist tracks full report comparison, localization, provider validation, signing and competitor workflow evidence.
