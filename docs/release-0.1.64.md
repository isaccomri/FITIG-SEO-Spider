# 0.1.64 — saved provider metrics

The Crawl reports workbench has 30 variants. Saved PageSpeed Metrics, Saved Search Console Metrics and Saved GA4 Metrics expose results already stored by the integrations. The tables support search and filtered CSV export.

Reports preserve zero values and leave unavailable metrics blank. The saved scope, date range and strategy appear above the table. Report generation reads local data. The PageSpeed table includes captured measurements. Opportunity and coverage exports require audit details that the saved integration does not retain.
