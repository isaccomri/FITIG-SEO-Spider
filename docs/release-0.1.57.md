# 0.1.57 — sitemap page inclusion and observed hreflang

Adds explicit opt-in controls to include successful HTML pages carrying observed noindex directives or a canonical pointing to another URL. Both remain excluded by default; unsuccessful responses, unavailable HTML extraction, external/fragment URLs and other existing exclusions still apply. Inclusion is a user-selected export decision, not a statement that those pages are indexable.

Adds observed hreflang annotations using the XHTML namespace alongside optional image extensions. Recorded language/URL pairs are deduplicated by lowercase language code and normalized URL. Conflicting targets, structurally invalid language codes, credentials, fragments, non-HTTP(S) URLs and missing self references reject export without replacing an existing package. A maximum of 500 recorded annotations per page is supported. The exporter does not infer languages or repair groups. Unknown target counts describe annotation associations absent from the saved crawl, not broken links. Language registry validity, reciprocal links and equivalent content are not certified. HTML observations are used; this change does not add HTTP Link-header discovery or cross-domain page crawling.

CLI flags: `--hreflang`, `--include-noindex-pages`, `--include-canonicalised-pages`. All default to false when omitted, including old options JSON. Optional annotations count toward uncompressed byte splitting but not the parent URL count. Readable Hebrew and XML escaping apply to both `loc` and alternate `href` values.

Reference: [Google localized versions and sitemap annotations](https://developers.google.com/search/docs/specialty/international/localized-versions), inspected 2026-10-31. Independent implementation; no claim of indexing outcomes or exact competitor equivalence.
