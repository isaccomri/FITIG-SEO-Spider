# 0.1.59 — hreflang and pagination report variants

Expands Reports → Crawl reports to fifteen report variants: the prior six redirect/canonical reports plus All hreflang URLs, Non-200 hreflang URLs, Unlinked hreflang URLs, Missing hreflang Return Links, Inconsistent Language & Region Return Links, Non Canonical Return Links, Noindex Return Links, Non-200 Pagination URLs and Unlinked Pagination URLs.

All use searchable, paged tables and filtered UTF-8 CSV. Hreflang status is blank for unobserved targets. Missing return links require an observed HTTP 200 HTML response with confirmed extraction; old records with unknown extraction are not declared missing. Return-language inconsistency compares target return labels with the source's recorded self-reference labels. No source self-language means that comparison is unverified. Unlinked means absence of saved internal anchor/area observations, not a proven site-wide absence. Noindex/canonical reports use recorded target restrictions and canonical destinations. They do not certify Google indexing or exact competitor semantics.

Pagination reports reuse the existing saved-source analyzer, including its HTTP/rendered source distinction, reciprocal-link evidence and missing-source inventory. Non-200 includes observed statuses other than 200, including an observed no-response status 0, and excludes uncrawled targets with unknown status. An unlinked pagination target may remain uncrawled; the report explicitly describes this bounded evidence. Reports make no network requests or database writes. Each report has an explicit 50,000-row limit.

Row 155 remains pending: the remaining report families and exact competitor output headers/semantics are not all implemented or compared. Fifteen implemented variants are a concrete feature count, not a percentage of complete equivalence. Signing and OpenAI setup prerequisites remain unresolved, and local implementation work remains.
